# Math Quest — Карта знаний

Публичная образовательная платформа для диагностики математических навыков.

## Продуктовая модель

- **Публичный режим:** ребёнок проходит диагностику без кода; результаты не отправляются на сервер.
- **Режим ученика:** вход по индивидуальному коду; попытки и динамика сохраняются.
- **Кабинет учителя:** управление группами и учениками, выдача и отзыв кодов, просмотр результатов и истории.

## Текущий модуль

1 класс · «Счёт в пределах 20» · 18 заданий · 6 навыков (S1–S6), по 3 задания на навык.

## Архитектура

- Frontend: HTML, CSS, JavaScript; предполагаемая публикация через GitHub Pages.
- Backend: Supabase PostgreSQL, Auth и Edge Functions.
- Браузер не получает service_role key и не читает таблицу правильных ответов.
- Проверка ответов, подсчёт баллов и запись попыток должны выполняться на сервере.

## Безопасность и приватность

Не хранить секреты в репозитории. Никогда не публиковать Supabase service_role key. Использовать минимальный набор данных детей, случайные высокоэнтропийные коды, безопасное хеширование, ограничение частоты запросов и отзыв кодов. Перед реальным использованием с детьми проверить требования GDPR и правила школы/родителей.
